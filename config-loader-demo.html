Config Loader Utility Demo

Demonstration of the centralized configuration loading system with caching and validation.

Basic Usage

1. Load Single Config

const allConfig = await ConfigLoader.load('all');
console.log(allConfig.repositories3x);

2. Load Multiple Configs

const configs = await ConfigLoader.loadMultiple(['all', 'values']);
console.log(configs.all, configs.values);

3. Get Specific Repository

const stash7 = await ConfigLoader.getRepository('stash7');
console.log(stash7);

4. Get Specific Value

const ending = await ConfigLoader.getValue('stash7Ending');
console.log('stash7Ending:', ending);

Advanced Features

5. Cache Management

// Get cache stats
const stats = ConfigLoader.getCacheStats();

// Clear specific cache
ConfigLoader.clearCache('all');

// Clear all cache
ConfigLoader.clearCache();

6. Force Reload (Skip Cache)

const fresh = await ConfigLoader.load('all', { skipCache: true });

7. Preload Configs

// Preload configs for better performance
await ConfigLoader.preload(['all', 'values', 'allrecent']);
